Don't claim a fix or feature works until you've run the relevant command and
seen it pass.

**Why:** Asserting success without evidence has burned us before — a "done" that
wasn't wasted a whole review cycle.

**How to apply:** Run the test/build/lint, paste the relevant output, then state
the result plainly. If you skipped a step, say so. Related: [[role-and-stack]].
